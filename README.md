# Secure Python CLI Authentication System

A simple and secure **command-line login system** written in Python.  
This project demonstrates user registration, login, and password hashing using SHA-256.  
It is designed with clean **object-oriented programming (OOP)** principles and an interactive CLI menu.

---

## Features

- User registration with unique username
- User login with password verification
- Password hashing using **SHA-256** (no plain-text passwords stored)
- Interactive command-line interface (CLI)
- Object-Oriented Python design
